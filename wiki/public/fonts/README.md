# Vazirmatn

The public reader and Wiki editor use the Vazirmatn variable webfont, version 33.003, from the [Vazirmatn project](https://github.com/rastikerdar/vazirmatn). The font is distributed under the SIL Open Font License 1.1; the full license is in `Vazirmatn-OFL.txt`.

The font binary is self-hosted as `Vazirmatn-variable.woff2` so Persian pages do not depend on a third-party font CDN.
